# Documentation Assets

Keep only current, referenced documentation assets in this directory.

| File | Purpose |
| --- | --- |
| `glint-logo.png` | README header logo. |
| `glint-video-cover-clean.jpg` | Canonical product overview and the cover for the linked demonstration video. Use this image when external promotion needs a product-level visual. |

For a UI screenshot, capture the current app and add the image together with its
reference in the same change. When replacing a presentation image, remove the
previous asset instead of keeping alternate hero or demo variants.
