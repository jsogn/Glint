# 主流语言扩展设计

- 状态：已实现，待发布验证
- 日期：2026-11-03
- 范围：中文简体候选到英语、日语、西班牙语、法语、德语或俄语翻译
- 目标分支：`codex/multilingual-expansion-research`

## 1. 结论

Glint 继续使用全局单目标语言模型。新增语言通过封闭的 `TranslationTarget` 枚举和
单一语言档案扩展，不引入任意 Locale、动态语言注册表或按模型名称推断能力。

英语保留现有 CC-CEDICT、ECDICT、词性、多释义和英语口音能力。日语、西班牙语、
法语、德语和俄语当前只使用模型翻译，不接入对应语言词典，不显示词性或释义数量。

Apple Translation 是所有目标语言的默认模型；首次使用某方向时由现有语言包安装
流程准备系统资源。MLX 等本地模型只能声明并验证自己实际支持的目标语言。

## 2. 语言档案

`TranslationTarget` 集中提供：

- 稳定 BCP-47 基础代码：`en`、`ja`、`es`、`fr`、`de`、`ru`
- 中文显示名和英文提示词名
- Apple Translation 使用的语言代码
- 语音 locale：`en-US`、`ja-JP`、`es-ES`、`fr-FR`、`de-DE`、`ru-RU`
- 词典、词性、多释义、口音和汉字输出能力

新增语言必须补充一个穷举语言档案和对应测试。不得通过模型 ID、显示名或字符串前缀
在路由、UI 或推理运行时中推断语言能力。

## 3. 模型与词典

- 英语继续允许“智能融合 / 词典优先 / 模型优先”。
- 非英语目标不执行词典查询，不显示翻译方式卡片。
- Apple Translation 默认模型对六种语言都可用；系统语言包未安装时显示安装动作。
- 每个目标语言独立保存最后一次选择的模型。
- 已有 `translation.modelID.en` 和 `translation.modelID.ja` 键保持兼容；新增语言
  使用 `translation.modelID.<target>`。
- 翻译模型 manifest 的 `translationTargets` 只用于声明已经确认的语言限制。缺少该
  字段表示不限制目标语言，允许用户自行选择并判断模型效果。
- 只有明确只有中英能力的模型声明 `["en"]`；多语言、通用模型和未知模型不显示语言
  能力标签，也不按目标语言过滤。
- 切换到某语言时，如果该语言保存的本地模型已不存在或不支持该语言，回退到
  Apple Translation 并更新该语言的选择；启动时已选模型缺失仍显式保留并报错，
  不静默替换用户原有的当前选择。
- MLX 引擎未收到能力限制时接受全部支持的目标语言，并使用显式目标语言生成请求；
  运行时只拒绝 manifest 明确排除的方向。

## 4. 语音

- 英语继续使用系统默认、美式和英式口音。
- 其他目标语言使用对应 locale 的系统语音，并提供“系统默认”或本机已安装语音。
- 音色偏好按目标语言独立保存，键为
  `general.translationSpeechVoice.<target>`。
- 切换目标语言时恢复该语言上次选择的音色；音色失效时静默回退该系统语言的默认语音。
- 用户主动改选音色或口音后，用目标语言固定样例立即试听。
- 英语语音缺失时不回落其他语言；非英语语音缺失时同样不回退英语。

## 5. 显示与输出

- 词性、多释义和英语专属显示能力仍只由英语能力声明开启。
- 非英语模型输出不得因为包含拉丁字母或西里尔字母被误判为中文回显。
- 只有日语允许高比例汉字输出；其他目标语言继续使用中文回显门控。
- HUD 预览为六种语言分别提供目标语言样例。

## 6. 验证

- GlintCore：语言档案、能力、文本门控、每语言模型和六目标协调器测试。
- GlintInference：六目标 prompt 名称、新语言输出清洗和声明能力测试。
- GlintMac：六目标 Apple Translation 可用性方向和会话切换测试。
- GlintUI：六目标页面渲染、HUD 样例、语音偏好和试听测试。
- GlintPlugins：六目标 manifest 编解码测试。
- 切换事务：语言、模型、启动准备、语言包刷新/准备和系统会话激活均带独立请求
  代次；旧代次只能结束自身任务，不能覆盖当前语言的 readiness、可用性、模型或
  播放状态。连续切换到同一最终语言也必须以最后一次请求为准。
- 真实主机验证：当前 macOS 26.6.2 上 `zh-Hans → es/fr/de/ru` 均返回
  `LanguageAvailability.supported`；语言包安装和逐语言翻译质量仍需发布前验证。
- `Resources/Evaluation/` 已为四种新语言各准备 30 条冒烟语料；安装语言包后执行
  对应 Apple Translation 评测，再补充发布级质量语料和母语者复核。
