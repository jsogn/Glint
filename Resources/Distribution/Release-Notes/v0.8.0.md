# Glint 0.8.0

## 更新内容

- 新增英语、日语、西班牙语、法语、德语和俄语学习语言切换
- 新增按学习语言保存翻译模型和朗读音色
- 新增其他语言 Apple 翻译语言包安装提示
- 新增 Apple 翻译语言包下载管理
- 新增已安装模型直接使用入口
- 优化 Apple 翻译语言包安装与继续安装流程
- 优化翻译模型状态与能力说明
- 优化语言包安装状态与操作区布局
- 优化朗读语音选择和试听
- 修复快速切换学习语言后译文或模型状态错乱
- 修复关闭系统下载面板后错误显示正在安装
- 修复关闭系统设置后 Glint 未回到前台
- 修复系统翻译状态检查可能无法结束

> Glint 通过 GitHub 发布无 Developer ID 签名的安装包。如遇 macOS 安全提示，
> 请在“隐私与安全性”中允许 Glint。

## 安装

推荐下载 PKG；也可使用 DMG。首次启动后，请在“辅助功能”中授权 Glint。

支持 macOS 15 及以上版本和 Apple Silicon Mac。
