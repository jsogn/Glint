# Glint 0.7.3

## 更新内容

- 选中单词时，可在英文译文后显示最多两个常用词性缩写，例如 `n./v.`、`adj.`。
- 新增“显示词性”开关，默认开启。
- macOS 26 及以上使用系统 Liquid Glass 翻译栏；系统会自动调整玻璃的明暗、
  透明度和辅助功能表现。
- 纯色翻译栏可独立调整背景颜色和不透明度。

> 当前为 ad-hoc 测试包。如遇 macOS 安全提示，请在“隐私与安全性”中允许 Glint。

## 安装

推荐下载 PKG；也可使用 DMG。首次启动后，请在“辅助功能”中授权 Glint。

支持 macOS 15 及以上版本和 Apple Silicon Mac。
