# Glint 0.7.2

这次更新新增了译文插入、朗读和更灵活的显示位置控制。

## 新增

- 可以在“显示与触发”中选择自动位置或“候选栏上方”。
- 可以为当前译文配置插入触发键，按“触发键 + `1–N`”直接插入对应译文。
- 可以按朗读触发键配合 `1–N` 试听译文，并在停顿后自动朗读当前主译文。
- 支持系统默认、美式英语和英式英语口音，以及较慢、标准和较快语速。
- 插入触发键和朗读触发键都可以清空；清空后不会注册对应全局快捷键。
- 快捷键朗读和自动朗读相互独立，可以只保留自动朗读。

## 改进

- 自动朗读可在 `0.5–3.0` 秒范围内设置停顿时间。
- 保存快捷键前会检查插入、朗读之间的冲突，以及系统或其他应用占用。
- 切换输入法、进入安全输入或停止监控时会立即停止对应朗读。

> 首次打开如遇 macOS 安全提示，请在“系统设置 → 隐私与安全性”中允许 Glint 打开。

## 安装

推荐下载 `Glint-*-macOS-arm64.pkg`，双击并按安装器提示完成安装。
也可以下载 DMG，将 Glint 拖入“应用程序”文件夹。

首次启动后，请在“系统设置 → 隐私与安全性 → 辅助功能”中授权 Glint。

## 系统要求

- macOS 15 或更高版本
- Apple Silicon Mac
