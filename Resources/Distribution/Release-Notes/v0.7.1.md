# Glint 0.7.1

这次更新修复了 Apple 翻译语言包安装不顺的问题。

- 关闭系统下载窗口后，可以直接继续安装。
- 语言包在后台下载完成后会自动更新状态，不需要重新打开 Glint。
- 继续安装会重新连接系统流程，不会删除已经下载的语言包。

> 首次打开如遇 macOS 安全提示，请在“系统设置 → 隐私与安全性”中允许 Glint 打开。

## 安装

推荐下载 `Glint-*-macOS-arm64.pkg`，双击并按安装器提示完成安装。
也可以下载 DMG，将 Glint 拖入“应用程序”文件夹。

首次启动后，请在“系统设置 → 隐私与安全性 → 辅助功能”中授权 Glint。

## 系统要求

- macOS 15 或更高版本
- Apple Silicon Mac
