# Glint 0.4.1

## 更新

- 新增开机自启动选项，可直接在通用配置中添加或移除登录项。
- 支持使用 `⌘W` 关闭主窗口、`⌘H` 隐藏 Glint、`⌘Q` 退出。
- 合并翻译设置与通用配置，让设置页面更简洁一致。
- 调整翻译显示按钮的颜色，降低关闭状态按钮的视觉干扰。

> 首次打开如遇 macOS 安全提示，请在“系统设置 → 隐私与安全性”中允许 Glint 打开。

## 安装

推荐下载 `Glint-*-Installer-macOS26-arm64.pkg`，双击并按安装器提示完成安装。
也可以下载 DMG，将 Glint 拖入“应用程序”文件夹。

首次启动后，请在“系统设置 → 隐私与安全性 → 辅助功能”中授权 Glint。

## 系统要求

- macOS 26 或更高版本
- Apple Silicon Mac
