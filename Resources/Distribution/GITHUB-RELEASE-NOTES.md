# Glint 0.5.0

## 更新

- 新增快捷插入：使用自定义触发键配合数字，将当前译文直接插入输入位置。
  不读取输入框正文，也不占用系统剪贴板。
- 新增“选中释义”和“一栏候选”两种显示模式，并可调整最多显示数量和释义间距。
- 新增词典在线更新与更稳定的释义排序；支持 CC-CEDICT、ECDICT 和 Wiktionary。
- 新增模型市场，可搜索并安装上游 MLX 翻译模型，也可导入本地模型。
- 改善模型安装前检查、下载进度和错误恢复。
- 修复候选窗翻到输入行上方时，翻译浮层可能覆盖输入行的问题。

> 首次打开如遇 macOS 安全提示，请在“系统设置 → 隐私与安全性”中允许 Glint 打开。

## 安装

推荐下载 `Glint-*-Installer-macOS26-arm64.pkg`，双击并按安装器提示完成安装。
也可以下载 DMG，将 Glint 拖入“应用程序”文件夹。

首次启动后，请在“系统设置 → 隐私与安全性 → 辅助功能”中授权 Glint。

## 系统要求

- macOS 26 或更高版本
- Apple Silicon Mac
