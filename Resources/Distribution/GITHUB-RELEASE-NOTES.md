# Glint 0.3.0

本次更新：

- 支持微信输入法高亮候选读取；样式不可读时回退到首候选。
- 支持搜狗拼音单行候选读取，并在“一栏”模式下显示整行翻译。
- 概览页显示系统输入法的真实本地化名称。
- 新增未知第三方输入法的通用 Profile 后台探测、限流和持久化缓存。
- 统一候选节点几何，改善搜狗默认皮肤的 HUD 间距。
- 恢复 macOS 26 工具栏页面标题的 Liquid Glass 胶囊背景。
- 调整主窗口默认尺寸并修复开发版本号回退显示。
- 更新 README、演示视频封面和产品演示入口。

---

输入中文拼音时，在候选栏旁查看对应的英文翻译。

Glint 不替换输入法，不读取输入框正文，所有翻译都在本机完成。

## 安装

1. 下载并打开 `Glint-*-macOS26-arm64.dmg`。
2. 将 Glint 移入“应用程序”文件夹，再从该位置启动。
3. 如果 macOS 提示无法验证应用，请在“系统设置 → 隐私与安全性”中确认。
4. 按提示授予辅助功能权限。

## 开始使用

切换到苹果拼音 `Pinyin - Simplified`，正常输入中文。对应英文翻译会出现在
候选栏旁。

## 系统要求

- macOS 26 或更高版本
- Apple Silicon Mac
