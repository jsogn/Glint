# Glint 0.6.0

## 重点更新

- 最低系统要求降至 macOS 15。
- Rime / 鼠须管候选读取支持正式上线，可在“输入法支持”中安装、重装或卸载，
  无需修改鼠须管应用本体。
- 优化菜单栏状态显示，翻译显示开启或关闭时使用明确且稳定的图标。
- 修复豆包输入法升级后候选读取失效的问题，并提升输入法版本更新、进程重启后的
  自动恢复能力。
- 校准 Apple 拼音候选栏旁译文的垂直间距，使显示位置更贴合当前输入行。

> 首次打开如遇 macOS 安全提示，请在“系统设置 → 隐私与安全性”中允许 Glint 打开。

## 安装

推荐下载 `Glint-*-macOS-arm64.pkg`，双击并按安装器提示完成安装。
也可以下载 DMG，将 Glint 拖入“应用程序”文件夹。

首次启动后，请在“系统设置 → 隐私与安全性 → 辅助功能”中授权 Glint。

## 系统要求

- macOS 15 或更高版本
- Apple Silicon Mac
