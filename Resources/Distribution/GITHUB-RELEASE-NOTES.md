输入中文拼音时，在候选栏旁查看对应的英文翻译。

Glint 不替换输入法，不读取输入框正文，所有翻译都在本机完成。

> 当前发布包使用 ad-hoc 签名，没有经过 Apple 公证，只适合开发和已知测试者。
> GitHub Latest 标记表示这是项目最新构建，不代表已经面向普通用户或通过
> Gatekeeper 验证。

## 安装

1. 下载并打开 `Glint-*-macOS26-arm64.dmg`。
2. 将 Glint 移入“应用程序”文件夹，再从该位置启动。
3. 如果 macOS 提示无法验证应用，请在“系统设置 → 隐私与安全性”中确认。
4. 按提示授予辅助功能权限。

## 开始使用

切换到苹果拼音 `Pinyin - Simplified`，正常输入中文。对应英文翻译会出现在
候选栏旁。

## 系统要求

- macOS 26 或更高版本
- Apple Silicon Mac
