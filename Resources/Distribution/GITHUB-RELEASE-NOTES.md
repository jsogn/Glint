# Glint 0.4.0

## 更新

- 新增豆包输入法候选识别，并继续支持苹果拼音、微信输入法和搜狗拼音。
- 扩展第三方输入法通用适配：具有相同候选结构的输入法可自动复用读取规则。
- 优化候选读取缓存和稳定候选期间的轮询频率，降低持续输入时的资源占用。
- 展开多行候选时更及时关闭翻译栏，收起后自动恢复。
- 改善输入法切换、重启和候选数量变化时的恢复能力。

> 首次打开如遇 macOS 安全提示，请在“系统设置 → 隐私与安全性”中允许 Glint 打开。

## 安装

推荐下载 `Glint-*-Installer-macOS26-arm64.pkg`，双击并按安装器提示完成安装。
也可以下载 DMG，将 Glint 拖入“应用程序”文件夹。

首次启动后，请在“系统设置 → 隐私与安全性 → 辅助功能”中授权 Glint。

## 系统要求

- macOS 26 或更高版本
- Apple Silicon Mac
