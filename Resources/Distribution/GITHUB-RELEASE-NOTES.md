# Glint 0.7.0

这次更新主要让 Glint 更轻、更快、更省心。

- 安装包体积大幅减少，下载和安装更快。
- Apple 翻译更好用，缺少语言包时可以直接按提示安装。
- 可选翻译模型改为按需安装，需要时再下载。
- 精简本地词典，占用更小，常用查词结果保持稳定。
- 调整候选停留和翻译栏间距，提示更及时，显示更自然。

> 首次打开如遇 macOS 安全提示，请在“系统设置 → 隐私与安全性”中允许 Glint 打开。

## 安装

推荐下载 `Glint-*-macOS-arm64.pkg`，双击并按安装器提示完成安装。
也可以下载 DMG，将 Glint 拖入“应用程序”文件夹。

首次启动后，请在“系统设置 → 隐私与安全性 → 辅助功能”中授权 Glint。

## 系统要求

- macOS 15 或更高版本
- Apple Silicon Mac
